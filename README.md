# Сайт по продаже туров

Платформа для подбора и бронирования туров.

## Функционал
- Список туров
- Страница тура
- Фильтры: страна, цена, даты
- Бронирование без реальной оплаты
- AI-чатбот для помощи в подборе туров

## Структура проекта
- `frontend/` - React приложение
- `backend/` - Node.js API с MongoDB
- `ai-rules/` - Правила для AI-ассистентов
- `docs/` - Документация

## Запуск
1. Установить зависимости: `npm install` в frontend и backend
2. Запустить backend: `npm start` в backend
3. Запустить frontend: `npm start` в frontend

## AI-правила
Каждый участник команды должен добавить свой файл в `ai-rules/` согласно формату.
