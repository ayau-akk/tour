# Сайт по продаже туров

Платформа для подбора и бронирования туров с AI-помощником.

## Функционал
- Список туров с фильтрами (страна, цена, даты)
- Страница тура
- Бронирование без реальной оплаты
- **AI-чатбот** для интеллектуального подбора туров

## Структура проекта
- `frontend/` - React приложение (порт 3000)
- `backend/` - Node.js API (порт 5001)
- `ai-chatbot/` - AI-помощник (порт 5002)
- `ai-rules/` - Правила для AI-ассистентов
- `docs/` - Документация

## Запуск проекта

### Требования
- Node.js 16+
- npm 7+

### Установка и запуск

#### 1. Backend (API)
```bash
cd backend
npm install
npm start
# Запустится на http://localhost:5001
```

#### 2. AI-Chatbot (в отдельном терминале)
```bash
cd ai-chatbot
npm install
npm start
# Запустится на http://localhost:5002
```

#### 3. Frontend (в отдельном терминале)
```bash
cd frontend
npm install
npm start
# Откроется на http://localhost:3000
```

## Использование AI-чатбота

1. Откройте приложение на http://localhost:3000
2. Нажмите кнопку "Открыть AI чат 🤖"
3. Расскажите AI о своем бюджете, интересующих странах или датах
4. AI подберет подходящие туры и покажет рекомендации

### Примеры запросов:
- "Мне нужен тур до 50000 рублей"
- "Интересует Франция"
- "Ищу тур в июне дешевле 60000"
- "Посоветуй романтический тур"

## AI-правила
Каждый участник команды должен добавить свой файл в `ai-rules/` согласно формату `role_name.md`.

## Разработка

### Структура компонентов Frontend
- `src/App.js` - Главный компонент с списком туров
- `src/ChatBot.js` - Компонент AI-чатбота
- `src/index.js` - Точка входа

### API Endpoints

#### Tours
- `GET /api/tours` - Получить список туров с фильтрами
  - Query params: `country`, `price`, `dates`
- `GET /api/tours/:id` - Получить тур по ID

#### Booking
- `POST /api/bookings` - Создать бронирование

#### AI Chat
- `POST /api/chat` - Отправить сообщение AI
  - Body: `{ "message": "..." }`
  - Response: `{ "response": "...", "recommendations": [...] }`
